No new toys today, just the pipes that make yesterday's toys hold. The vault left Microsoft's house: everything now syncs to a private GitHub repo through Obsidian Git, pull on startup and push every ten minutes, one source of truth with no upkeep. (Life, Influence.)

And the Newsroom went self-publishing. The Daily Brief and this record now post to a live page on their own, a GitHub Action mirroring each edition from the private vault to a public repo with no hand-holding. Edition 002 is the first proof the pipe works end to end. (Influence, Impact.)

Named honestly, still open: the Roll-Up runs on vault scraps until a real connector is wired, the market-posture call is still unmade two days running, and a self-publishing paper still needs a verify step before a half-baked draft ships itself to the open web. Boring day. The best kind. Boring is what shipping looks like when the foundation holds.
